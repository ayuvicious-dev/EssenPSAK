# EssenPSAK
Aplikasi Belajar PSAK (PWA). Login & penyimpanan memakai Firebase (Authentication Email/Password + Firestore). Tidak ada fitur daftar: akun dibuat di Firebase console.

Deploy: upload semua file ke repository GitHub, aktifkan GitHub Pages (branch main, folder root).
Update berikutnya cukup menimpa `index.html`.
